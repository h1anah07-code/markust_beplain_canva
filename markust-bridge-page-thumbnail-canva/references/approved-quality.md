For beplain use light #F7F7FA/white, navy #202D83, secondary #5B5D66 and body #111217 unless requested otherwise. Times New Roman Bold editorial headings, Arial regular/bold support/product/labels/CTA; a focused short headline may use bold Arial. Do not replace approved styling with mint/cream cards, sparse slogan cards or small cutout portraits. The source JSON starter preserves historical geometry; adapt new copy without treating old sizes as limits. Existing wording revisions preserve current styles.

At 1600px width, new-layout starting points: headings 88–112px, useful support 42–52px, CTA 40–48px, state labels 34–40px. These are source sizes, not CSS minima or universal pixel/point conversion. Use restrained bold and navy to emphasize key benefit/ingredient. Never enlarge all text or shrink useful copy to force fit. Outer alignment is typically x60–80; preserve reference group proportions and intentional breathing room. Exact historical coordinates remain in the unchanged JSON template, not another competing rule table.

Photo framing should look intentional and large: natural hair/background edge crops are acceptable; clipping central features, stretching, floating scraps or inconsistent comparison scale are not. Source pose must be 0°–45°; cropping cannot change pose. In 01, labels sit inside photos bottom-right. In 04, inset is Before and large main photo After, each labeled bottom-right. Only 05 requires identical comparison viewpoints; angle differences in full-face layouts are not efficacy evidence.

Use the latest bundled transparent beplain-logo.png at top-left. Preserve alpha/proportions, no white badge, and a light background under the black mark. A different brand needs its own official asset. A packshot is optional and must be supplied/authorized official, never generated or a competitor product.

Inspect at 400–600px page width and native detail: useful support, hierarchy, logo alpha, crop, labels, alignment, whitespace, line breaks, no overlap/clipping, individually editable native objects. Actual Canva reflow is authoritative; a local preview/font file cannot prove Canva fonts or heights. Record omitted native properties as unverified, never as passed.
