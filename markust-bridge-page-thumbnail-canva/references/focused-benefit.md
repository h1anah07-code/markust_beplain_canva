# Structure 05: one appeal, matching skin-region views

Use assets/focused-benefit-template.json. This is a one-page starter, not a mandatory fifth page. Composition: official top-left logo, product identity, short single-benefit headline, matching Before/After crops and transition, one supported reason, CTA; optional authorized official packshot subordinate to the pair. State labels must not obscure target skin.

Prepare a brief per visualizable appeal: identity/anchor, anatomical region, allowed visible change, unaffected features, source roles, provenance and caption. Match pose within 0°–45°, anatomical landmarks, scale, light/exposure and expression. Cheek dryness and eye-area lines need relevant distinct pairs; never reuse a general transformation as proof of unrelated effects. Full-face angle flexibility does not apply here.

- Suitable supplied actual pair: crop/scale only, retain source/conditions, do not infer product causality.
- Verified authorized concept pair: reuse only if the intended feature and matching region fit.
- Authorized missing pair: use ImageGen after inspecting references; preserve identity and only the selected feature. For a focused-only request, generate the requested pair, not an unwanted three-state/four-angle set. When both Markust skills are invoked, preserve the image skill's requested three PNG deliverables and generate only missing supplemental pairs.
- Without generation authorization or a suitable pair: continue copy/layout preparation and ask for the missing input; never relabel two same-state angles.

Absorption, non-sticky feel, tolerability and barrier function are not proved by ordinary facial photos. Use actual supplied application/texture material or sourced tests. Competitor visuals inspire layout only; no transferred results/percentages/packaging. No invented clinical charts or time claims.

Record generated provenance internally. Artwork omits AI-related wording per the user's preference; use readable “Illustrative comparison; not actual product-use results.” near conceptual comparisons, or “Illustrative texture comparison; not a performance test.” when applicable. Actual result materials retain their conditions/source. Disclosure never licenses an unsupported efficacy claim.

QA before Canva and at final scale: same region/identity/landmarks/pose/light, only intended feature changes, ordinary pores, immediately visible natural difference without zoom/blink/filter, no cracks/age change/plastic smoothing. Correct only the failed region with ImageGen, maximum three retries for the same strength issue; report remaining limitations honestly. Final native layout must preserve that evidence, readability and accurate labels.
