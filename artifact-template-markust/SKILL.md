# Markust 비포·애프터

사용자의 최신 지시가 우선한다. 기본 결과는 `before.png`, `middle.png`, `after.png` **3장, 각각 정면·약 30도·40도·90도 네 컷**이다. 효율을 이유로 상태·각도·해상도·검수를 줄이지 않는다.

## 입력과 연결
- 제공된 사진/영상, 소구점, 인물 조건, 원본 상태를 먼저 확인한다. 근거가 없는 필수 입력만 한 번에 묻는다.
- Canva 스킬과 함께 호출되면 Canva가 전체 작업을 관리한다. 같은 작업의 `brief.json` 및 `photos/handoff.json`을 읽고 분석·근거 수집·생성을 반복하지 않는다. 연결 계약은 [handoff.md](references/handoff.md). 단독 사용은 이 스킬만으로 완료한다.
- 새 인물·나이·원본 역할·소구점으로 바뀌면 해당 이미지와 파생 결과만 무효화한다. 다른 인물의 이전 이미지를 재사용하지 않는다.
- 애프터 원본이면 그 피부 수준을 최종 기준으로 유지하고 비포/중간을 재구성한다. 비포 원본이면 첫 비포를 유지하고 절제된 최종 개선과 중간을 만든다. 고정은 인물·피부 기준이며 없는 각도를 원본과 픽셀 동일하다고 주장하지 않는다.
- 대상 나이·민감 피부·무자극 같은 속성을 사진으로 증명되는 효과로 바꾸지 않는다. 참고 여성의 얼굴·나이·의상은 새 인물에 적용하지 않는다.

## 생성
1. `artifact-template.json`과 [visual-reference.md](references/visual-reference.md)를 읽고 해당 참고를 확인한다. 같은 작업에서 이미 확인한 참고는 변경 또는 판단 미해결 때만 다시 연다.
2. `$imagegen`과 내장 이미지 생성 도구를 사용한다. 로컬 입력은 먼저 이미지 보기로 확인한다. 피부 편집을 코드/필터로 대신하지 않는다.
3. 원본 역할에 맞는 네 각도 기준을 만든다. 이미 조건을 만족하는 기준 시트는 그대로 재사용한다.
4. [prompting.md](references/prompting.md)의 기준/상태 프롬프트와 해당 소구점 지침을 사용한다. 각 생성 호출에 인물·피부·각도·촬영 조건 유지 지시를 전달한다. 프롬프트의 유지 조건을 토큰 절약 때문에 생략하지 않는다.
5. 첫 비포와 최종 애프터를 먼저 만든 뒤 축소 비교를 통과시키고 중간 한 장을 만든다. 기준 상태가 이미 완성된 출력이면 다시 생성하지 않는다. 상태가 섞이면 동일 기준 시트 하나를 편집 대상으로 좁혀 해당 단계만 고친다.

## 품질과 전달
- 각 시트: 동일 크기 가로형, 동일 폭 네 컷 한 줄, 화면 오른쪽 30/40/90도, 30도와 40도 구분, 얼굴 전체~쇄골, 눈높이·얼굴 크기 일치, 얇은 흰 세로선. 이마·턱·코를 자르지 않는다. **이미지 안에는 글자·숫자·라벨·날짜·로고가 없어야 한다.**
- 기본 변화는 현재 소구점 각각이 썸네일에서 분명하게 구분되는 자연스러운 강도다. 다른 피부 특징·얼굴형·나이·메이크업·헤어·의상·표정·배경·빛·색온도를 바꿔 차이를 만들지 않는다. 원본으로 고정한 상태는 유지한다.
- 첫 비포/최종 애프터의 정면을 같은 크롭·얼굴 크기, 각각 폭 320–400px로 나란히 직접 확인한다. 확대·깜빡임·강조 필터 없이 각 소구점 차이가 보여야 한다. 네 각도 모두 일관되고 중간은 양 끝과 구별되어야 한다.
- 플라스틱 피부, 반복 무늬, 교차선·균열, 질병 같은 과장, 인물/각도 변형은 결함이다. 해당 부위만 수정·재검수한다. 같은 강도 문제는 최대 3회 수정 후 미해결 한계를 보고한다. 사용자에게 ‘더 티나게’ 재요청을 기다리지 않는다.
- 검수한 세 PNG와 실제 프롬프트를 새 작업 `outputs` 폴더에 보존하고 비포→중간→애프터 순서로 표시해 다운로드/프롬프트 링크를 제공한다. 원본을 덮어쓰지 않는다. 각도는 근사치이며 생성물을 실제 제품 사용 기록이라고 설명하지 않는다.
- 연결 실행도 세 PNG 전달을 생략하지 않는다. Canva 배치 이후에는 Canva 스킬이 최종 배율 검수를 맡는다. 같은 원본에 대한 중복 검수가 아니라 배치 변경의 검수다.
