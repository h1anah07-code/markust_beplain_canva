# 승인된 시각 참고

## 파일과 역할

| 파일 | 용도 |
|---|---|
| `../assets/reference.png` | 승인된 최종 애프터. 네 각도 배치, 얼굴~쇄골 프레이밍, 자연스러운 피부결의 기준. |
| `../assets/preview.png` | 위 애프터를 수정 없이 복사한 갤러리 미리보기. |
| `../assets/before-01.png` | 과거 첫 비포의 주름·붉은기 수준 참고. 현재 첫 비포의 강도를 이 보관본에 고정하지 않는다. |
| `../assets/before-02.png` | 중간 상태의 자연스러운 피부 변화 참고. 최종 중간 상태는 이번 비포와 애프터 사이에서 정한다. |
| `../assets/before-03.png` | 과거의 애프터 직전 강도를 보관한 참고. 추가 출력 단계가 아니며 네 번째 최종 파일을 만들지 않는다. |

사용자는 이 대화의 자연스러운 결과와 비포 사진 사이의 변화가 좋다고 평가했고, 2026-10-10 최신 피드백으로 기본 구성을 비포·중간·애프터 각 1장, 총 3장으로 변경했다. 각 장에는 기존과 동일하게 네 각도를 담고 글자를 넣지 않는다. 보관된 비포 파일 수는 최종 출력 수를 뜻하지 않는다.

## 적용 범위

- 보관된 PNG는 이 스킬의 독립적인 시각 참고이며 원본 Downloads 경로나 이전 대화의 파일에 의존하지 않는다.
- 레이아웃, 모공·잔주름을 남긴 피부 표현, 자연스러움을 참고한다. 실제 인물·피부 기준은 새 요청에 첨부된 사진이다. 보관된 비포의 변화 강도는 상한이나 고정값이 아니다.
- 최신 사용자 피드백에 따라 기본 강도는 **썸네일 크기에서 바로 구분되는 초기·최종 차이**다. 사용자의 ‘더 티나게’ 재요청을 기다리지 않는다. 보관된 예시의 미세한 차이를 기본 강도나 상한으로 복제하지 않고, 현재 소구점에 따른 실제 축소 비교로 판정한다. 애프터가 원본 기준이면 그 수준은 유지하고 첫 비포의 소구점 관련 국소 표현을 충분히 눈에 띄게 한다. 중간 한 장으로 차이가 자연스럽게 줄어드는 상태를 연결한다.
- 보관된 여성은 사용자가 같은 예시 인물을 다시 요청하거나 이 템플릿 인물을 쓰려는 경우에 사용할 수 있다. 이 보관본의 원본 역할은 애프터다.
- 새 인물 사진이 있는 경우 예시 여성 PNG를 인물 참조로 함께 입력하지 않는다. 얼굴이 섞이지 않도록 생성 도구에는 이번 사용자의 인물 기준을 전달한다.
- 주름·붉은기를 모든 제품의 기본 소구점으로 취급하지 않는다. 새 소구점의 시각적 표현을 정한 후 같은 자연스러움과 출력 구조를 적용한다.
- 첫 비포와 애프터의 대비도 그때의 소구점만 기준으로 만든다. 다른 소구점에서는 이 예시의 주름·홍조를 그대로 덧붙이지 않는다.
